Política de Privacidad de PokéDex

Última actualización: 20 de agosto de 2026

Esta Política de Privacidad explica cómo se gestionan los datos cuando utilizas PokéDex (en adelante, la "Aplicación").

PokéDex es una aplicación destinada a consultar y explorar información relacionada con Pokémon.

1. Responsable de la aplicación

El responsable de PokéDex es:

  • Desarrollador: AlmarpaDev
  • Aplicación: PokéDex
  • Contacto: almarpa.dev@gmail.com

2. Información personal

PokéDex no requiere que el usuario cree una cuenta y no solicita directamente información personal identificable, como nombre, dirección de correo electrónico, número de teléfono, dirección postal o fecha de nacimiento.

La Aplicación tampoco solicita acceso a contactos, cámara, micrófono, SMS, registro de llamadas, fotografías personales ni otros datos personales similares.

3. Datos del dispositivo

PokéDex no recopila deliberadamente información personal para identificar al usuario.

La utilización de servicios de red puede implicar el tratamiento de información técnica necesaria para establecer y mantener una conexión, como la dirección IP del dispositivo o información técnica de la conexión.

4. Datos almacenados en el dispositivo

PokéDex puede almacenar información localmente en el dispositivo para proporcionar sus funcionalidades, mejorar el rendimiento y permitir determinadas funciones de la aplicación.

Estos datos se almacenan localmente en el dispositivo y no se transmiten al desarrollador como información personal.

El usuario puede eliminar los datos almacenados por la Aplicación mediante las opciones de almacenamiento del sistema operativo o desinstalando la Aplicación.

5. Servicios externos

PokéDex utiliza servicios externos para obtener información y recursos necesarios para mostrar contenido relacionado con Pokémon.

Para realizar estas solicitudes, la Aplicación puede comunicarse con servidores de terceros. Estas comunicaciones pueden incluir información técnica necesaria para realizar la conexión, como la dirección IP del dispositivo.

El tratamiento de información realizado directamente por estos servicios externos está sujeto a sus propias políticas de privacidad y condiciones de uso.

6. Compartición de datos

El desarrollador de PokéDex no vende, alquila ni comparte información personal de los usuarios con terceros con fines publicitarios o comerciales.

La Aplicación no está diseñada para crear perfiles personales de los usuarios ni para realizar seguimiento publicitario.

7. Publicidad

La versión actual de PokéDex no contiene publicidad.

Si en el futuro se incorporan servicios publicitarios que impliquen el tratamiento de datos de usuario, esta Política de Privacidad será actualizada para reflejar dicho cambio.

8. Analítica y seguimiento

La versión actual de PokéDex no utiliza servicios de analítica destinados a realizar un seguimiento personal de los usuarios.

La Aplicación tampoco utiliza tecnologías de seguimiento con fines publicitarios.

9. Seguridad

Se aplican medidas razonables para proteger la información gestionada por la Aplicación.

Cuando la Aplicación se comunica con servicios externos, se utilizan conexiones seguras mediante HTTPS cuando dichos servicios lo permiten.

No obstante, ningún método de transmisión o almacenamiento electrónico puede garantizar una seguridad absoluta.

10. Conservación y eliminación de datos

PokéDex no mantiene actualmente cuentas de usuario ni una base de datos propia que almacene información personal identificable de los usuarios.

Los datos almacenados localmente por la Aplicación pueden eliminarse mediante las opciones de almacenamiento disponibles en el dispositivo o desinstalando la Aplicación.

Los datos que puedan ser procesados por servicios externos están sujetos a las políticas de conservación y eliminación de dichos servicios.

11. Privacidad de menores

PokéDex no está diseñada específicamente para recopilar información personal de menores.

La Aplicación no solicita deliberadamente información personal identificable a niños.

Si un padre, madre o tutor considera que un menor ha proporcionado información personal a través de la Aplicación, puede ponerse en contacto con el desarrollador utilizando la dirección indicada en esta política.

12. Cambios en esta Política de Privacidad

Esta Política de Privacidad puede actualizarse periódicamente para reflejar cambios en la Aplicación, en los servicios utilizados o en los requisitos legales aplicables.

Cuando se produzcan cambios relevantes, se actualizará la fecha de "Última actualización" indicada al principio de esta página.
